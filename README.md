# Sentinel Frontend
Magic
This project is built using React, TypeScript, and Vite.

## Installation

To install the project dependencies, run:

```bash
npm install
```

## Run Locally

To start the application locally, run:

```bash
npm run dev
```

Open the localhost URL displayed in the terminal, usually http://localhost:5173.

## Build

To build the application, run:

```bash
npm run build
```

## Technologies

- React
- TypeScript
- Vite
- React Router
- ESLint
